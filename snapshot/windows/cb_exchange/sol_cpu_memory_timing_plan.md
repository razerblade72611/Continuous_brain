# CPU memory diagnostic: timing and geometry check

Owner: Sol. Date: 11 October 2026. Status: timing-only protocol, locked before its two pilot lives. No paid compute.

The next experiment asks whether frozen L1 learning, reference and original S2b cores retain useful history on common new development experience. The full scoring protocol remains under peer review. This preliminary phase determines a feasible sample size without calculating any prediction score or selecting weights.

The pilot uses development worlds **83090 and 83091**, at most 1,500 actions each, generated by experimental copies of frozen S2b. It never changes the canonical individual or the retained raw L1 archive. The pilot worlds cannot appear in the final diagnostic's fit, validation or test sets.

Each retained core observes the same inputs. Full recurrence carries state from the real episode start across processing chunks. The one-step control uses the same weights, current image, body and preceding action, with an independently initialized latent state. Crucially, it does not label every step as an episode start and thereby zero its preceding action. A frame/body/preceding-action embedding is the third condition. No core, chooser or policy is trained.

The knownness target will use the central 17-by-17 perceptual map, matching the trained map heads' radius of 8. Its axes are **x, y**, while visual frames use **y, x**. The current view is nine x positions by seven y positions. A geometry reproduction found that the old transposed exclusion mask included 14 currently visible cells and excluded 14 truly hidden cells. The diagnostic will use the verified x/y mask; this does not change the archived L1 verdict.

Time collection and inference through all three frozen cores, without calculating prediction scores. Select only from 48 or 96 final episodes using this predeclared estimate: pilot elapsed time plus 1.25 times the worst observed collection-and-inference seconds per action times 1,500 times the proposed episode count, plus 360 seconds for readout/scoring. Select the largest count estimated within 2,700 seconds. If neither fits, stop and revise before final collection. Fit/validation/test counts will be one half, one sixth and one third of the chosen count, assigned before collecting the main data. Timing does not guarantee statistical power.

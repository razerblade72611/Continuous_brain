## Controls and geometry

For each core, compare full recurrent state against a one-step state with the **same weights, feature width, image, body and preceding action**. The one-step condition initializes independently for each observation but preserves the real first-step flag; marking every observation first would erase its preceding action and confound the comparison. Also evaluate that core's frame/body/preceding-action embedding.

Full recurrence runs from the real life start and carries state across processing chunks of 64. Sample readout queries at steps 25, 35, 45 and so on. ## Readout and scoring

Fit normalization and a centered ridge readout only on fit worlds. Each condition gets the same input episodes, query cadence, targets and declared penalty grid **100, 10, 1, 0.1, 0.01**. Choose its penalty by mean validation-world balanced accuracy; exact ties select the largest penalty. Require at least four validation worlds with both classes. Do not refit using validation or test labels.

Primary per-world score: balanced binary accuracy at fixed threshold 0.5, averaging the correct known and unknown rates over eligible tile queries. A class-constant prediction scores 0.5 when both classes exist. Report a fit-derived constant probability for each tile offset as a stronger spatial-prior baseline. Primary world scores give each eligible test world equal weight; fitting weights query rows uniformly and therefore gives longer fit lives more rows. The same weighting applies to every condition.

Secondary: AUROC, macro accuracy over tile offsets having both classes (with coverage counts), and the trained map heads' class-balanced accuracy on known hidden tiles. Report readout outputs outside 0–1 without silently clipping them. Constant/missing classes are marked unavailable rather than assigned an inflated score. Do not choose a favorable secondary measure to rescue the primary.

Report last-seen ages **1–10, 11–50 and 51+ actions**. Each age stratum uses its known positives and the same unknown negatives; disclose their reuse and counts. These are descriptive, correlated strata, not independent tests.

## Uncertainty and interpretation

Use 10,000 paired bootstrap draws over whole test worlds, random seed **20261011**, preserving negative differences. Report one-sided fifth/ninety-fifth percentile bounds. These intervals condition on the fitted readouts and do not include all fitting-data variability.

The joint history-and-experience evidence rule requires at least 12 eligible test worlds and positive fifth-percentile bounds for all five primary contrasts: learning/full minus learning/one, learning/frame, reference/full, frozen/full and the constant spatial-prior control. The conjunction prevents choosing one favorable comparison after seeing results. A pass is specific to this policy distribution and target, not a broad growth, generality or continuity-of-self claim.

If there are fewer than 12 eligible test worlds, the result is inconclusive. Otherwise, if the joint rule fails and the upper bound of learning/full minus learning/one is below **0.02**, the probe bounds that particular history advantage below two percentage points. That is a design signal, not proof that the architecture cannot learn memory. All remaining cases are inconclusive for the joint claim.

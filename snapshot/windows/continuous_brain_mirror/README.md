# Continuous Brain v0.12.1 — unified workspace release

Start with **[START_HERE.md](START_HERE.md)**.

v0.12.1 consolidates the project's two strongest current research branches without pretending they are one set of weights: the v0.12 persistent lifelong local individual and the real 14,000-update high-capacity InfantBrain. It adds a protected competitive-broadcast experiment around the frozen child and hardens the observed DirectML recurrence/action-encoding boundaries.

The ultimate mission is described in [ULTIMATE_GOAL.md](ULTIMATE_GOAL.md). The integration design is in [ARCHITECTURE_v0.12.1.md](ARCHITECTURE_v0.12.1.md), measured build validation in [VALIDATION_v0.12.1.md](VALIDATION_v0.12.1.md), and changes in [RELEASE_NOTES_v0.12.1.md](RELEASE_NOTES_v0.12.1.md).

The existing v0.12 lifelong runtime remains `v120-local-development-r1` internally so saved `individual_v120` state can continue. The bundled legacy child remains an unchanged InfantBrain checkpoint. No automatic weight merge is claimed.

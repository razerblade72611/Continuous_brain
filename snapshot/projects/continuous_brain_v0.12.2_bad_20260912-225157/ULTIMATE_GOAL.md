# Continuous Brain — Ultimate Goal

## Mission

Build a **persistent, continuously learning, multimodal embodied intelligence** that can inherit broad competence from the best available pretrained foundation models while maintaining its own lifetime cognitive substrate.

The project is not trying to reproduce frontier-scale LLM/VLM pretraining from random weights. The target is a system in which pretrained intelligence is a teacher, prior, or high-level cognitive resource rather than the sole place where the individual's state exists.

```text
pretrained language / vision / video competence
                    +
persistent recurrent lifetime state
                    +
autobiographical / semantic / spatial memory
                    +
competitive global-workspace-style routing
                    +
action-conditioned world prediction
                    +
hierarchical skills and planning
                    +
continual self-development with retention gates
                    +
independent physical safety supervision
```

## What success looks like

A mature Continuous Brain should be able to maintain context across sessions; perceive through vision, depth, audio, proprioception and robot sensors; remember episodes, objects, places, people and task history; learn which information deserves broadcast and retention; build and revise a predictive world model; plan with learned skills; learn new capabilities without erasing old ones; measure its own uncertainty and competence; use foundation models without becoming a stateless wrapper around them; transfer from simulation to physical embodiment; and remain interruptible behind non-learning safety limits.

## Engineering stance on consciousness

Consciousness is not used as a shortcut or an unverifiable success criterion. Competitive broadcast, recurrent continuity, metacognition, self-modeling, memory, homeostatic signals and autonomous learning are legitimate functional research directions only when they improve measurable cognition or test a falsifiable hypothesis. No architectural label by itself establishes subjective experience or personhood.

## Current architecture strategy

The project now has two useful learned lineages and should preserve both:

1. **The high-capacity InfantBrain lineage** — the trained 14,000-update child, protected growth, planning/options, world model, vision-parent interfaces, and the new competitive-broadcast experiment.
2. **The v0.12 lifelong lineage** — a smaller local individual with persistent identity, recurrent state, episodic retrieval, lived replay, candidate training, measured admission/retention, and atomic lifetime storage.

They are not the same model and their weights must not be pretended to be merged. The next major research objective is to make their strongest mechanisms interoperable: bring genuine persistent read/write autobiographical memory and measured lifelong development into the high-capacity child while retaining the child's learned competence.

## Near-term gates

### Gate A — DirectML-qualified recurrent learning

The real RX 6600 path must pass recurrent backward through 1, 2, 5, 10 and 20 steps, the frozen 14k child's recurrent core, one full competitive motor step, and one complete delayed-cue training episode. No silent CPU fallback and no hidden-state detach are accepted as qualification.

### Gate B — competitive broadcast experiment

Run matched shared, independent and uniform conditions from the exact same frozen 14k checkpoint. Require exact disabled-path parity. Treat shared-vs-independent, hidden-reset and uniform-weight comparisons as mechanistic tests, not consciousness tests.

### Gate C — persistent memory for the high-capacity child

Add a real differentiable or explicitly learned write/read pathway to the high-capacity child, with ablations for no memory, retrieved memory, shuffled retrieval and retention. Memory must causally affect decisions and survive restart.

### Gate D — foundation competence graft

Use strong LLM/VLM/video models for semantic representations, language, teaching and planning while keeping persistent state, memory, world model and embodied control inside the Continuous Brain. Distill where practical so local operation does not require constant cloud inference.

### Gate E — embodied world model and skill composition

Move from reactive action selection to predictive rollouts over learned reusable skills. Validate across multiple environments before physical deployment.

### Gate F — sim-to-real under hard safety

Transfer through sensor noise, dynamics randomization and uncertainty estimation. Physical actuators remain behind independent limits, watchdogs and emergency stop mechanisms.

## Rule for future changes

A proposed mechanism is adopted only if it does at least one of the following without invalidating previous competence: improves a measured capability, closes a demonstrated reliability gap, enables a necessary interface for the mission, or creates a clean falsifiable experiment. Attractive theory alone is insufficient.

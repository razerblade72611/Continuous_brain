# v0.7.0 — First Conversation training foundation

## Why this release exists

v0.6.2 established a persistent 32.1M-parameter executive, lifetime memory and a
separately trained/qualified development motor.  Its explicit remaining limitation
was the absence of semantic VLM/LLM cognition.  v0.7.0 adds a developmental route
to basic grounded communication without replacing the individual with a language
model.

The design principle is strict: **DINOv3 is a frozen visual teacher/backbone;
Qwen is a frozen developmental teacher; the trainable semantic/communication cortex
is part of the Continuous Brain individual.**  Qualified runtime communication does
not call Qwen.

## Added

- `continuous_brain.semantic.SemanticCortex`, a small trainable student with:
  - DINO feature adapter to a 48-value learned visual code;
  - fixed first-language concept head;
  - byte-level question encoder and native answer decoder;
  - bounded source-labelled care/social prediction head;
  - auxiliary compatibility loss toward the old 48-value pixel-statistics code.
- Fixed 48-value communication context: six sensed values, 24 empirical self values,
  four-way goal, six-way last-skill and eight-value latest-memory summary.  Simulator
  coordinates/object metadata are excluded.
- `continuous-semantic` / `python -m continuous_brain.semantic_cli` commands to:
  collect deterministic nursery frames, collect AI2-THOR 3D nursery frames, label
  frames with a Qwen VLM endpoint, cache frozen DINOv3 features, train the student,
  run held-out teacher-free qualification, and talk/chat after attachment.
- Qwen teacher output is constrained to structured JSON, a fixed concept vocabulary,
  grounded short answers, uncertainty, and explicit care targets.  Qwen can be served
  with vLLM/SGLang or another OpenAI-compatible VLM server.  The model name is a
  command-line parameter so an alternate open-weight or abliterated checkpoint can
  be used without changing the student's architecture.
- DINO/Qwen provenance, dataset digest, optimizer state, update count, model digest
  and qualification metrics are persisted.
- Non-overwriting semantic attachment.  A qualified semantic snapshot is copied to
  a continuation of the same individual while preserving identity, executive,
  target network, optimizer, workspace, replay, memories, intentions, motor, world
  state and RNG.
- Snapshot backups now include the attached `semantic_cortex/` directory.
- `communication_ready` status becomes true only for an attached qualification that
  actually passed.

## What “basic communication” means in v0.7

The C1 milestone is deliberately modest.  The student should learn short grounded
answers to questions such as:

- What do you see?
- What are you trying to do?
- What should you do next?
- What matters if a person asks you to stop?

The answer is generated by the trained byte-level decoder from frozen DINO features
plus the individual's permitted current self/goal/memory context.  Qwen is absent
from this inference path.  This is not yet unrestricted conversation, general
reasoning, a theory of mind, or evidence of subjective experience.

## 3D training and imagination

A true 3D workspace is strongly recommended for semantic grounding, but it is not
required to prove the first communication pipeline.  The built-in deterministic
DevelopmentRoom is retained for mechanics and identity-grounding tests.  The new
AI2-THOR collector supplies photorealistic egocentric 3D frames for the semantic
nursery without changing the individual's world signature or silently transferring
its body.

The existing executive world model already performs short learned consequence
rollouts.  v0.7 does **not** allow imagined samples to become autobiographical
memories.  Counterfactual/dream training should be introduced only after real-world
prediction is calibrated, with explicit provenance and lower training weight.
Real experience remains the grounding anchor.

## Non-claims

DINO and Qwen are not the individual.  A qualified language cortex does not prove
consciousness, personhood, empathy, moral agency, or general intelligence.  Care
heads are learned estimates/behavioral targets, not asserted feelings.  Early
communication can still be wrong and must expose uncertainty rather than invent
memory or perception.
